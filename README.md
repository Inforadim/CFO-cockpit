# CFO Cockpit

An interactive CFO dashboard I designed to illustrate how I turn financial data into management priorities and actions.

**All data is fictional.** The company "Meridian Cloud, Inc." and every figure in the dashboard are invented for demonstration. No real company data is used.

## What it shows
- A ranked list of findings, each with financial exposure, a recommended action, an owner and a deadline
- Overview, profitability, cash and customers views (24 months of data)
- A "Check of actual figures" page that recomputes the headline numbers from the source data

## How to use
Open the page in any modern browser. Everything runs locally in the browser; nothing is sent anywhere.
